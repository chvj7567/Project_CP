# CatPang

> Android 모바일 매치-3 퍼즐 게임 | Unity 개인 개발 프로젝트

---

## 게임 소개

**CatPang**은 고양이를 테마로 한 모바일 퍼즐 게임입니다.
9×9 격자판 위에서 블록을 밀어 3개 이상 같은 색을 맞추면 터지는 고전적인 매치-3 방식에,
폭탄 블록·보스 스테이지·스킨 시스템 등 다양한 요소를 더해 플레이의 변화를 줬습니다.

| | |
|---|---|
| **장르** | 매치-3 퍼즐 |
| **플랫폼** | Android (Google Play) |
| **개발 환경** | Unity 6 / Windows |
| **개발 형태** | 1인 개인 개발 |

---

## 게임 특징

### 세 가지 모드, 400개 스테이지

- **노멀 모드** — 이동 횟수 제한 없음, 여유롭게 클리어
- **하드 모드** — 시간 제한 추가. 같은 맵을 빠르게 풀어야 하는 도전 버전
- **보스 스테이지** — 10스테이지마다 등장하는 보스. 벽 생성·블록 소환 등 고유 패턴으로 방해

### 다양한 블록 종류

일반 고양이 블록 외에 **폭탄 블록**(범위 폭발), **벽 블록**(이동 불가), **포탈 블록**(위치 순간 이동), **레인보우 블록**(전체 색 제거) 등 총 80여 종의 블록이 등장합니다. 블록 조합에 따라 전략이 달라집니다.

### 고양이 스킨 컬렉션

왕관·딸기·산타 등 6가지 테마 스킨을 수집할 수 있습니다. 스킨은 블록 외형에 반영되어 시각적 다양성을 줍니다.

### 일일 미션 & 출석 보상

매일 초기화되는 미션(스테이지 클리어·블록 파괴·광고 시청·출석 체크)을 완료하면 아이템을 획득합니다. 서버 시각을 기준으로 자정에 리셋되어 기기 시각 조작을 방지합니다.

## 게임 플레이 가이드

### 기본 규칙

9×9 판에서 고양이 블록을 상하좌우로 밀어 **같은 색 3개 이상** 또는 **2×2 정사각형**을 맞추면 블록이 터집니다. 빈 자리는 위에서 새 블록이 채워지며 연쇄가 이어집니다.

### 특수블록 만들기

매치 모양에 따라 더 강력한 특수블록이 생깁니다.

| 이렇게 맞추면 | 이런 블록이 생겨요 | 터뜨리면 |
|---|---|---|
| 2×2 정사각형 | **캣팡** | 주변 3×3 폭발 |
| 가로 4개 이상 | **가로 화살표** | 가로 한 줄 제거 |
| 세로 4개 이상 | **세로 화살표** | 세로 한 줄 제거 |
| 가로+세로 교차 | **십자/X 화살표** | 십자 또는 대각선 전체 제거 |

특수블록 **둘을 맞붙이면** 더 큰 효과가 나옵니다 — 색폭탄끼리는 **전체 폭발**, 핑크폭탄은 **맞붙인 색을 보드에서 전부 제거**, 화살표끼리는 **색폭탄으로 합성**됩니다. **레인보우 블록**은 보드 전체에 색폭탄을 흩뿌립니다.

### 장애물 블록 없애기

| 블록 | 없애는 법 |
|---|---|
| **벽 / 포탈** | 바로 옆에서 매치를 터뜨려 데미지를 줘 부숩니다 |
| **고양이 상자** | 상자 **바로 위 칸**에 상자가 원하는 색 고양이를 보내 담습니다 |
| **물고기** | 매치로 아래로 흘려보내 **맨 아래줄까지 도착**시키면 탈출합니다 |
| **공(Ball)** | 폭탄으로 직접 터뜨리거나, 맨 아래줄까지 굴려보냅니다 |
| **생성기(벽/포탈)** | 매 턴 주변에 장애물을 만들어내므로, 옆에서 매치해 먼저 부숴야 합니다 |

> 스테이지 클리어 조건은 보통 **HP를 가진 특수블록(벽·상자 등)과 물고기·공을 모두 없애는 것**입니다. 일반 고양이 블록은 목표가 아닙니다.

## 구현 범위

### 게임플레이 시스템

- **보드 엔진** — 9×9 그리드 상태 관리, 블록 드래그 입력 처리, 중력(블록 낙하·채우기)
- **매치 판정** — 가로/세로 3매치 + 2×2 정사각형 매치 동시 지원
- **연쇄 폭발** — 폭탄이 인접 폭탄을 순차 트리거하는 체인 처리
- **보스 AI** — 스테이지마다 다른 패턴(벽 소환·블록 생성·고양이 상자)으로 플레이어를 방해
- **튜토리얼** — 게임 첫 진입 시 단계별 안내 시퀀스

### 데이터 & 저장

- 로컬 저장(JSON) + Google Play 클라우드 저장 자동 동기화
- NTP 서버 시각 기반 일일 미션 리셋 (기기 시각 위변조 대응)
- 스테이지 진행도·아이템 수량·미션 상태 등 저장 관리

### 수익화 & 소셜

- Google AdMob 광고 (배너·전면·보상형)
- Unity IAP 인앱 결제 (소모성 아이템)
- Google Play Games 로그인 + 리더보드

### 개발 생산성 도구

에디터 내에서 동작하는 자체 제작 툴들:

- **스테이지 에디터** — 9×9 그리드를 마우스로 직접 배치해 JSON으로 저장, 400개 스테이지 모두 이 툴로 제작
- **게임뷰 해상도 프리셋** — 기기별 해상도를 메뉴 한 번으로 전환
- **로컬라이제이션 관리** — 한국어/영어 문자열 일괄 편집

### 재사용 인프라 패키지

게임과 분리된 UPM 패키지(`com.chvj.unityinfra`)로 리소스 로딩·UI 캐싱·오브젝트 풀·오디오·광고/IAP/소셜 모듈을 묶어 관리합니다. 다른 프로젝트에서도 그대로 가져다 쓸 수 있는 구조로 설계했습니다.
