1. **노출 시점·트리거**
   스테이지 40(그룹 4 마지막)을 클리어하는 즉시 스테이지 41(그룹 5 첫 번째)이 잠금 해제된다. 게임은 플레이어에게 난이도 변화를 알리는 별도 알림·튜토리얼 없이 자동으로 다음 스테이지를 열어 준다. 이 시점이 btc=4→5 전환의 유일한 진입점이다.

2. **화면 변화**
   스테이지 41 보드가 열리면 기존 4가지 색보다 하나 더 많은 5가지 고양이 색 블록이 전체 보드를 채운다. 보드 시각 밀도와 색 분포 복잡도가 이전 10개 스테이지(그룹 4, btc=4)와 뚜렷하게 달라지며, 플레이어는 한눈에 "패턴 찾기가 어려워졌다"는 느낌을 받는다. 어떤 UI 경고나 새 색 도입 연출도 없다.

3. **입력 행동**
   플레이어는 같은 색 블록 3개를 한 줄에 모을 조합을 탐색하며 블록을 드래그한다. btc=5 환경에서는 특정 색이 전체 블록의 약 20%만 차지하므로(btc=4일 때 25%), 3-매치 형성 확률이 통계적으로 낮아지고 더 많은 드래그 시도가 필요하다.

4. **시스템 반응**
   GPMatchChecker의 매치 판정, GPBoard의 블록 하강, GPBombResolver의 특수폭탄 생성 로직은 btc=4 스테이지와 동일하게 작동한다. 다만 같은 횟수의 드래그 대비 연쇄(콤보) 발생 빈도는 낮아진다 — 색 혼잡도 증가로 인접 색 일치 확률이 줄기 때문이다.

5. **반복·재발생 패턴**
   그룹 5(스테이지 41)부터 그룹 15(스테이지 150)까지 110개 스테이지가 같은 btc=5 구조를 반복한다. 그룹 6 내 1개 예외(btc=4)를 제외하면 플레이어는 스테이지 41 이후 109번 연속으로 동일한 색 복잡도를 경험한다. 노멀 모드로 전환해도 btc=5는 유지되므로 "쉬운 모드"에서도 색 혼잡도 완화 효과는 없다.

6. **종료·해소 조건**

7. **다른 시스템과 상호작용**

9. **유저 정보·피드백**
   현재 게임에는 btc 변화를 플레이어에게 알리는 UI 메시지나 진행 피드백이 없다. 플레이어는 "갑자기 어려워졌다"는 감각적 인식만 가지며, 이것이 색 복잡도 때문인지 다른 요소(moveCount 증가 등) 때문인지 구분하기 어렵다. 적절한 시각 연출(예: "새로운 색 등장!" 알림)이나 btc=4 완화 스테이지를 배치하면 플레이어 인식 개선과 이탈 방지 효과를 모두 기대할 수 있다.
